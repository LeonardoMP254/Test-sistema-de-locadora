# 🎭 Sistema de Locadora de Fantasias

## 📌 Sobre o Projeto

Este projeto foi desenvolvido a partir de um sistema originalmente baseado em **Carros e Motos**, onde a proposta da atividade era realizar a adaptação completa do sistema para um novo tema.

O tema escolhido foi **Locadora de Fantasias**, exigindo alterações em toda a estrutura do projeto para que o sistema fizesse sentido dentro do novo contexto.

Foram realizadas mudanças em:

* Estrutura das classes
* Modelos
* Serviços
* Interface do usuário
* Dados JSON
* Funcionalidades do sistema
* Nomenclaturas do projeto
* Organização do código

O sistema permite o gerenciamento de fantasias para aluguel, simulando uma locadora com diferentes categorias e status de disponibilidade.
